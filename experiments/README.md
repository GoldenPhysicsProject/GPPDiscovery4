# experiments/

Runnable numeric/symbolic experiments. Convention (Codex process):

- Every experiment is a **script**, never a pasted output. A result without its
  script is a rumor.
- Scripts print their parameters and write machine-readable output
  (append to `../results.jsonl` where practical).
- Name: `YYYY-MM-DD_topic.py` (or `.lean` for symbolic checks).

Planned: Ritz/theta-control tests, dyadic prime-sum experiments, F_θ
adversarial controls for candidate estimates.
